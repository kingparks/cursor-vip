# Contributing to cursor-vip

Thank you for contributing to cursor-vip!

## Development Setup

1. **Requirements** - Go 1.21+, Git
2. **Clone** - `git clone https://github.com/kingparks/cursor-vip.git`
3. **Install** - `go mod download`
4. **Test** - `go test ./...`

## Making Changes

1. Create a feature branch: `git checkout -b feat/your-feature`
2. Make your changes
3. Run `go fmt` and `go vet` before committing
4. Commit and push
5. Submit a PR

## Pull Request Process

1. Fork the repository
2. Create your feature branch
3. Make your changes with tests
4. Submit a PR with description
